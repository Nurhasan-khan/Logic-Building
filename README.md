# 🧠 Logic-Building & DSA Practice

This repository is a **personal logic-building and DSA practice collection**, where I store solved problems while improving my problem-solving and coding skills.

The main goal of this repo is to:
- Strengthen **logical thinking**
- Practice **Data Structures & Algorithms**
- Build consistency through daily/regular coding

---

## 📁 Repository Structure
Logic-Building/
│
├── arrays/ # Array-based problems (e.g., subarrays, prefix sums)
├── basic/maths/ # Mathematical problems and number logic
├── conditional_thinking/ # Problems focused on decision-making logic
├── hashing/ # HashMap, frequency counting, prefix hashing
├── looping_patterns/ # Pattern-based and loop-based problems

## 📈 Learning Approach

Instead of memorizing solutions, I focus on:

- Understanding the **pattern behind problems**
- Breaking problems into **smaller logical steps**
- Comparing **brute force vs optimized approaches**
- Practicing **multiple variations of the same concept**
